# 界面截图清单

本目录存放 README 引用的界面截图。截图由项目成员补充，文件名和对应页面如下；
README 中的引用路径已按这些文件名写好，补齐文件即生效。

建议尺寸：宽 1200–1600 px，PNG 格式；截取时页面 URL 带 `?source=auto`，
使用记录页的数据来源选 auto，与验证流程（docs/VALIDATION.md）一致。
