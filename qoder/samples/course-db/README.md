# 示例课程：《数据库系统原理》（2026 秋）

这是一门**虚构但内容准确**的课程资料包，用来演示和验证考前雷达。它模拟一名学生期末前手里的真实资料状况：
有的章节笔记记得很全，有的只记了几句，有的完全没记，而往年试卷恰好考过。

| 文件 | 类型 | 内容 | 覆盖的考点 |
| --- | --- | --- | --- |
| `notes/02-SQL速记.md` | 笔记 notes | 第 2 章 SQL，只记了基本查询和分组，没有视图、子查询 | 2（薄弱） |
| `notes/03-索引与B+树.md` | 笔记 notes | 第 3 章，B+树结构、插入分裂、聚簇索引、哈希索引，记得很全 | 3 |
| `notes/05-事务与并发控制.md` | 笔记 notes | 第 5 章，ACID、可串行化、两阶段锁、死锁记得很全；隔离级别和 MVCC 只有两句 | 6、7，8（薄弱） |
| `slides/第7讲-故障恢复.pdf` | 课件 slides | 9 页课件：故障类型、日志、WAL、undo/redo、检查点、ARIES、CLR | 9 |
| `papers/two-phase-commit-primer.pdf` | 论文 paper | 2 页英文阅读材料：两阶段提交及其阻塞问题 | 10 |
| `exams/2025-2026-1-期末试卷A.pdf` | 往年试卷 exam | 2 页、11 道题、满分 100，每题标了分值 | 1–10 都考到 |
| `syllabus.txt` | 考试范围 | 老师公布的 10 个知识点 | — |

设计上的"盲区"：考点 1（关系代数）、4（函数依赖与范式，试卷里占 25 分）、5（查询优化）在笔记、课件和阅读材料里都没有；
考点 2（SQL 与视图）和 8（隔离级别与 MVCC）只有零星几句。

## 设计真值（用于校准和验收覆盖雷达）

| id | 知识点（`syllabus.txt`） | 资料里的覆盖 | 往年试卷（题号:分值） |
| --- | --- | --- | --- |
| t01 | 关系模型与关系代数 | missing | 1:5 |
| t02 | SQL 查询与视图 | thin | 2:10 |
| t03 | 索引：B+树与哈希索引 | covered | 3:10 |
| t04 | 函数依赖与范式（3NF、BCNF） | missing | 4:15，5:10 |
| t05 | 查询处理与优化 | missing | 6:5 |
| t06 | 事务的 ACID 特性 | covered | 7:5 |
| t07 | 并发控制：两阶段锁与死锁 | covered | 8:10 |
| t08 | 隔离级别与 MVCC | thin | 9:10 |
| t09 | 故障恢复：WAL 与 ARIES | covered | 10:10 |

所以最大的盲区是 t04：笔记里一个字没有，往年试卷却占 25 分。

另外，课件和试卷 PDF 是用 macOS 中文字体导出的，从中抽取的文字里有大量"康熙部首"兼容字符（例如 `⽇志` 里的 `⽇` 是 U+2F47，
不是"日" U+65E5），这和很多真实的中文 PDF 一样，导入时必须做 Unicode 归一化，否则全文检索搜不到"日志"。
