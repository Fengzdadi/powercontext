考前雷达EXAMRADAR

把散落的笔记、课件和往年试卷变成一张考前覆盖雷达：哪些考点往年分值最高、你的资料里却没记，考前一眼看清。

看示例雷达 代码仓库

解决的问题

大学生期末复习时，三个反复出现的痛点：

01

资料散

课堂笔记（Markdown）、老师的课件（PDF）、往年试卷（PDF）、拓展阅读的论文（中英文 PDF）分散在各处，想找“上次笔记里讲两阶段锁的那段”要翻半天。

02

不知道自己漏了什么

老师公布了考试范围，但没人告诉你哪几章自己的笔记根本没记、哪些只记了一两句，而往年真题恰恰常考这些。

03

复习没有记性

刷题工具不知道你上次错在哪，每次都从头来；错题本靠手抄，复习间隔全凭感觉。

核心功能

本地运行、无模型依赖：配置大模型时体验更好，不配置时全部功能依然完整可用。

导入资料 + 问笔记

导入 Markdown、纯文本和 PDF 资料（笔记 / 课件 / 往年试卷 / 论文），切块入库后用混合检索问答。

  • 向量检索 + IK 全文检索，RRF 融合，中英文都能搜；
  • 每条结果带出处：文件 · 第几页 · 标题路径；
  • 配置大模型时生成带 [1][2] 引用的回答，未配置时直接展示带出处的原文段落。

考前覆盖雷达

粘贴老师给的考试范围，对每个知识点在资料里找证据、做判定。

  • 逐个考点检索，判定已覆盖 / 薄弱 / 缺失，每个判定写明理由；
  • 往年试卷按题归属到知识点，计算考试分值权重；
  • 盲区按“分值 × 未覆盖”排序，最大的漏洞排最前。

复习教练

只从你自己的资料里出题，优先针对薄弱、缺失和到期复习的知识点。

  • 出题、判分都标明出自哪份资料哪一页；
  • 配置大模型时出选择题和简答题；没配置大模型时，从这个知识点找到考点词的笔记段落里挖空，出填空题；
  • 资料里没有的知识点（判定为缺失）用往年原题自测，学习者自评“会 / 模糊 / 不会”；
  • Leitner 间隔复习：5 个盒子、间隔 1 / 2 / 4 / 7 / 14 天，答对升级、答错回 1 号盒。

学习者记忆

越用越懂你：每次判分都写进长期记忆，下次打开从记忆开始。

  • 掌握度卡片：每次判分产生新的 revision，历次变化就是掌握度轨迹；
  • 错题和复习计划自动记录，不用手抄；
  • 新会话开场白，例如“上次你在 X 上错了 2 次，先复习这个”。

使用记录

真实记录每一次使用，数据可核对。

  • 学习会话、检索、覆盖分析、出题答题全程记录；
  • 真实使用与开发测试数据分开统计，互不掺水；
  • 可导出 CSV / JSON。

seekdb 与 PowerContext 的分工

两个基础设施各管一件事：seekdb 是课程知识库，存资料、做检索；PowerContext 是学习者的记忆，存掌握度、错题和复习计划。两者都在主流程里真实起作用。

seekdb = 课程知识库PowerContext = 学习者的记忆
存什么 资料切块（documents / chunks 表：正文、标题路径、页码、试卷题号与分值、向量）；使用记录（usage_events 表） 每个学习者 × 课程一个 Scope；掌握度卡片、错题、复习计划、会话小结等原子记忆
在哪些功能起作用 导入资料、问笔记、覆盖雷达、使用记录 复习教练、学习者记忆、新会话开场白
怎么核对 检索走 DBMS_HYBRID_SEARCH（向量 + IK 全文，RRF 融合）；用 DBMS_HYBRID_SEARCH.GET_SQL 可以看到实际执行的 SQL，每条检索结果都带出处 每次判分产生新的 revision（掌握度变化轨迹）；记忆带标签（如 type-mastery、bootstrap-context）；会话开始 / 进入知识点走 context/bootstrap 和 context/prepare 两个上下文接口

体验区：示例课程的覆盖雷达快照

数据来自样例课程《数据库系统原理》（示例课程资料包）的真实分析结果导出：对 10 个考试知识点逐个检索判定，往年试卷 11 道题、满分 100 分。点开盲区可以看到支撑判定的证据、出处和关联试题。

这是示例数据的静态快照，覆盖判定和分数以导出文件为准；完整功能（导入自己的资料、粘贴自己的考试范围、出题复习）请在本地运行。Docker 一键启动命令见下方。
